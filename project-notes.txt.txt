Git — це розподілена система контролю версій, яка дозволяє відстежувати зміни у вихідному коді, повертатися до попередніх станів та працювати в команді без втрати даних.

GitHub — це хмарна платформа та вебсервіс для хостингу IT-проєктів та їхньої спільної розробки. Вона використовує Git під капотом, надаючи зручний інтерфейс для взаємодії (пул-реквести, обговорення, відстеження помилок).
