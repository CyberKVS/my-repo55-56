1.Навчальний проєкт на тему **«Моє Репо»**.
2.У проєкті потрібно попрактикувати роботу з локальним Git репозиторієм,
комітами, гілками, віддаленим репозиторієм GitHub, файлами `.gitignore`, командами `push`,
`pull`, `clone`, а також створенням Pull Request.
3.У фінальному репозиторії мають бути файли

* `README.md`
* `commands.txt`
* `project-notes.txt`
* `.gitignore`
* `git-rules.txt`
* `github-info.txt`
