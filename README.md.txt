1.Навчальний проєкт на тему **«Моє Репо»**.
2.У проєкті потрібно попрактикувати роботу з локальним Git репозиторієм,
комітами, гілками, віддаленим репозиторієм GitHub, файлами `.gitignore`, командами `push`,
`pull`, `clone`, а також створенням Pull Request.
3.У фінальному репозиторії мають бути файли

* `README.md`
* `commands.txt`
* `project-notes.txt`
* `.gitignore`
* `git-rules.txt`
* `github-info.txt`                 
Висновок 
•	Призначення GitHub: Платформа для хостингу коду, спільної розробки та контролю версій на базі системи Git.
•	Локальний репозиторій: Версія проєкту на вашому комп'ютері, де ви створюєте, редагуєте та зберігаєте файли й історію їхніх змін.
•	Зв'язок локального та віддаленого репозиторіїв: Здійснюється через додавання віддаленої адреси за допомогою команди git remote add origin <URL_репозиторію>.
•	Основний процес роботи:
o	Збереження змін локально (git add та git commit).
o	Відправка коду на GitHub (git push).
o	Оновлення локальної версії з сервера (git pull).
