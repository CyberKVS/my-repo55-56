GitHub — це хмарне сховище для програмного коду та інструмент для спільної розробки, який працює як «Google Диск», але спеціально створений для збереження історії змін і командної роботи над програмами. 
(Примітка: набір літер «erhf]ycmrj. vjdj.» у вашому запитанні — це випадково набране на клавіатурі «докладна мова / повне відео», написане в іншій розкладці).
Для чого він потрібен:
•	Зберігання коду в інтернеті: Ваш код не зникне, якщо зламається комп'ютер.
•	Контроль версій: Дозволяє бачити всі зміни в коді, порівнювати старі й нові версії та за потреби повертатися до попереднього робочого стану.
•	Командна робота: Кілька людей можуть одночасно працювати над одним проєктом, не перезаписуючи код один одного.
•	Портфоліо для розробника: Проєкти на GitHub слугують «резюме», за яким майбутні роботодавці можуть оцінити ваші навички. 
Ви можете почати роботу безпосередньо на офіційному сайті GitHub.
